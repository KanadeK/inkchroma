# Changelog

All notable changes to InkChroma are documented here.

## [0.1.0] - 2026-08-27

### Added

- Offline PNG/JPEG strip analysis with row-local paper normalization and CIE Lab
  profiles.
- Contiguous visible-band summaries and transparent ±2-point pair alignment.
- Deterministic JSON, CSV, standalone SVG, and script-free HTML reports.
- Actionable invalid-project, image, coordinate, signal, and output-path failures.
- Synthetic success, different-size boundary, and blank-strip failure examples.
- One local/CI release gate covering quality, tests, audit, packaging, clean wheel
  installation, and the installed console entry.
